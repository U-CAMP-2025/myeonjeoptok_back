# 협업 기반 면접 연습 플랫폼 - 면접톡

## 프로젝트 소개

> '함께 성장하는 면접 시뮬레이션 환경'을 목표로, 기존의 *비효율적이고 고립된 면접 준비 과정을 개선하는 통합 웹 플랫폼*입니다. 
지원자들이 **면접 노트(질문-답변 세트)를 공유**하고, **실전과 유사한 환경에서 모의 면접을 연습**하며, **상호 피드백을 통해 효율적으로 성장**할 수 있도록 돕습니다.

## 주요 기능
| 유저 / 관리자 | 면접 노트 | 면접 연습 | 결제 |
|--------------|-----------|-----------|-------|
| 카카오 소셜 로그인 | 면접 노트 작성 | 면접 연습 생성 | 플러스 이용권 결제 |
| 회원 가입 / 탈퇴 | 면접 노트 조회 | 면접 연습 진행 | 결제 내역 확인 |
| 마이페이지 | 면접 노트 스크랩 | 음성 → 텍스트 변환(STT) |  |
| 합격자 신청 | 면접 노트 리뷰 | AI 피드백 / 셀프 피드백 |  |
| 관리자 승인 / 유저 관리 |  | 랭킹 제공 |  |
| 알림 기능 |  |  |  |
